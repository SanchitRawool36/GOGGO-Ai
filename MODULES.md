# GOGGO-AI Modules

## Runtime

Coordinates the overall autonomous execution loop.

## Planner

Breaks goals into structured task plans.

## Task Manager

Tracks tasks and their lifecycle.

## Repository Intelligence

Parses, indexes, and understands repository structure.

## Tool Layer

Provides filesystem, Python, shell, and git capabilities.

## Builder

Builds or scaffolds new project structures.

## Memory

Stores agent- and company-level knowledge.

## Execution

Runs tasks, tools, tests, and healing steps.
